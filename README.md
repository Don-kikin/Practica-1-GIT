# Fundamentos de Python: Variables, Tipos de Datos y Entrada/Salida

Este repositorio contiene un script introductorio diseñado para ilustrar los conceptos básicos del lenguaje Python, incluyendo la declaración de variables, el reconocimiento de tipos de datos simples y la interacción con el usuario mediante la consola.

## Propósito del Proyecto

El código sirve como material de estudio y referencia para comprender:
* Qué son las variables y cómo funcionan como espacios de memoria.
* Los cuatro tipos de datos simples en Python (Strings, Enteros, Flotantes y Booleanos).
* El uso de comillas simples, dobles y triples para cadenas de texto.
* La captura de datos del usuario mediante la función `input()`.
* La concatenación de variables de texto y su salida en pantalla mediante `print()`.

## Requisitos Previos

* Python 3.x instalado en tu entorno local.

## Instalación y Ejecución

1. Descarga o clona este repositorio en tu equipo.
2. Abre tu terminal de comandos y dirígete a la carpeta que contiene el archivo `.py`.
3. Ejecuta el script con el siguiente comando:

   ```bash
   python nombre_del_archivo.py

   Uso
